 ***Note***
 
This the code of the paper——**UTCMapper for 0.3 m urban tree canopy mapping: a case study in Shanghai**, which is currently under peer review. Once the manuscript is accepted, the project will be open-sourced upon reaching a ready stage.
***
***Highlights***

 - A deep learning framework for UTC mapping without manual labels was  
   proposed.
 - Novel network, loss, and training strategy were developed.
 - The first 0.3 m UTC map of Shanghai was generated.
 - The influence on urban applications was discussed.
 - The proposed framework supports extention to national-scale mapping.
